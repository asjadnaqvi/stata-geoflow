# geoflow v1.1
(30 Oct 2026)

A Stata module for generating spatial arcs.


## Installation

The package can be installed via SSC or GitHub. The GitHub version, *might* be more recent due to bug fixes, feature updates etc, and *may* contain syntax improvements and changes in *default* values. See version numbers below. Eventually the GitHub version is published on SSC.

The SSC version (**v1.0**):

```stata
ssc install geoflow, replace
```

Or it can be installed from GitHub (**v1.1**):

```stata
net install geoflow, from("https://raw.githubusercontent.com/asjadnaqvi/stata-geoflow/main/installation/") replace
```

Install the following dependencies:

```stata
ssc install graphfunctions, replace
```

The map examples also require `geoframe` and `geoplot`:

```stata
ssc install geoframe, replace
net install geoplot, from("https://raw.githubusercontent.com/benjann/geoplot/main/") replace
```

Additional code for the maps shown below:


```stata
ssc install schemepack, replace
set scheme white_tableau  

graph set window fontface "Arial Narrow"
```

## Syntax



```stata
geoflow numvar [if] [in] using filename, from(varname) to(varname) key(varname) save(filename) [replace groups(integer) top(integer) points(integer) geoframe radius(real) arrow mark]

```


The package assumes that the users have the following two files:

- **file1**: This file should contain a numeric numvar flow variable defined by *from()* and *to()* identifiers. This file should already be loaded before using the command.
- **file2**: This file should contain a unique *key()* variable for which coordinates are defined and can be merged with *from()* and *to()* variables in **file1**.

The node dataset must contain numeric `_ID`, `_CX`, and `_CY` variables. These are generated by default if `spshape2dta` is used. The `key()` variable belongs to this dataset and need not exist in the loaded flow data.



See `help geoflow` for details.

If `radius()` is omitted, `geoflow` automatically uses the longest source-to-destination straight-line distance among the selected, matched flows as a shared radius. This adapts to the coordinate units and extent rather than assuming a fixed radius of 350. An explicit `radius(#)` must be positive and at least half the longest selected distance. Smaller radii give more curved arcs. The chosen value is returned in `r(arcradius)`. Exclude flows with missing coordinates, nonfinite distances, or coincident endpoints before generating arcs.


## Examples

Get the global boundary data using the latest version of the [geoboundary](https://github.com/asjadnaqvi/stata-geoboundary) package:

```stata
geoboundary WLD, replace convert remove source(worldbank) 
```

Clean it up since ISO3 values can have duplicates due to territories:

```stata
use WB_ADM0, clear
	duplicates list ISO_A3
	drop if ISO_A3=="-99"
	drop if TYPE=="Dependency"
	drop if inlist(WB_A3, "BES", "TKL")

isid ISO_A3
compress
save iso_meta, replace 
```

This creates our master node attributes file that also contains the coordinates.


Load the sample trade data file derived from COMTRADE [BACI](https://www.cepii.fr/CEPII/en/bdd_modele/bdd_modele_item.asp?id=37) for 2022:

```stata
use "https://github.com/asjadnaqvi/stata-geoflow/blob/main/GIS/baci_2022.dta?raw=true", clear
```

Create flow arcs for the top 20 values:

```stata
geoflow value using iso_meta, from(ex_iso3) to(im_iso3) key(ISO_A3) top(20) ///
    save(links) geoframe replace mark
```

Also see `return list`, which stores the radius value in `r(arcradius)`. Since we specified the `geoframe` option, we can view the data by switching to this frame: `frame change links`.

Now create another frame that contains the boundaries and the node attributes:

```stata
geoframe create metadata iso_meta, replace shp(WB_ADM0_shp)
```

Here we use the cleaned node file for the attributes. The shape frame `WB_ADM0_shp` must be available from the boundary-data setup. Keep the trade data in the `default` frame so the following examples can reuse it.

Plot the information:

```stata
geoplot ///
	 (area metadata i.REGION_WB, color(%40) lw(0.1) lc(white))	///
	 (line links i._ID, lwidth(0.4) color(black) )	///
	 (point metadata [w=GDP_MD_EST] if _mark==1, color(white%95) msize(1.6) mlcolor(black) )	///
	 (label metadata ISO_A3 		if _mark==1, color(black)   size(1.5)  			 )	///
	 , tight legend(pos(7)) ///
	 title("Top 20 trade flows in 2022") note("Source: COMTRADE BACI")
```

<img src="/GIS/geoflow1.png" width="100%">

The node markers are scaled by `GDP_MD_EST`. The `mark` option overwrites `_mark` in the node dataset and saves that dataset back to disk: participating nodes receive 1 and other nodes receive missing. Recreate or reload `metadata` after each use of `mark` to display the updated selection.

The `arrow` option adds the endpoint coordinates used by a `pcarrow` layer. Set arrowhead size directly with the layer's `msize()` option. The arrow points from `from()` to `to()`.

### Showcase arrows without node markers

Node markers can cover arrowheads at the destinations. Omit the point and label layers to show the arrows clearly. Generate arrow coordinates and use `msize(2)` for the arrowheads:

```stata
frame change default
geoflow value using iso_meta, from(ex_iso3) to(im_iso3) key(ISO_A3) ///
    top(20) save(links_large_arrows) geoframe replace arrow

geoplot ///
    (area metadata i.REGION_WB, color(%40) lw(0.1) lc(white)) ///
    (line links_large_arrows i._ID, lwidth(0.4) color(black)) ///
    (pcarrow links_large_arrows, ///
        coordinates(_arrow_x1 _arrow_y1 _arrow_x2 _arrow_y2) ///
        msize(2) lcolor(black) mcolor(black)), ///
    tight legend(pos(7)) ///
    title("Top 20 trade flows: arrows without nodes") ///
    note("Source: COMTRADE BACI")
```

<img src="/GIS/geoflow1_arrows_large.png" width="100%">

### Filter flows to or from one country

Use an `if` qualifier to focus on flows involving a particular country. This example keeps the 20 largest flows to or from China:

```stata
frame change default
geoflow value if ex_iso3=="CHN" | im_iso3=="CHN" using iso_meta, ///
    from(ex_iso3) to(im_iso3) key(ISO_A3) top(20) ///
    save(china_flows) geoframe replace mark

geoframe create metadata iso_meta, replace shp(WB_ADM0_shp)

geoplot ///
    (area metadata i.REGION_WB, color(%40) lw(0.1) lc(white)) ///
    (line china_flows i._ID, lwidth(0.4) color(black)) ///
    (point metadata [w=GDP_MD_EST] if _mark==1, ///
        color(white%95) msize(1.6) mlcolor(black)) ///
    (label metadata ISO_A3 if _mark==1, color(black) size(1.5)), ///
    tight legend(pos(7)) title("Trade flows to and from China") ///
    note("Source: COMTRADE BACI")
```

<img src="/GIS/geoflow_china_arrows.png" width="100%">

Despite the historical image filename, this example uses scaled nodes without arrows. Only the node-free example above overlays arrowheads.

### Group flows into quantiles

The `groups()` option adds a quantile-group variable to the arc data. Here, the 100 largest flows are split into five groups:

```stata
frame change default
geoflow value using iso_meta, from(ex_iso3) to(im_iso3) key(ISO_A3) ///
    top(100) groups(5) save(flow_groups) geoframe replace

frame change flow_groups
tabulate _group
```

The `_group` variable can be used to distinguish flow-size groups in subsequent plots.

The examples use the included 2022 trade-flow sample and map files in `GIS/`.
